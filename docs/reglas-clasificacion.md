# Reglas de clasificación de prospectos

## Objetivo

Priorizar empresas con una oportunidad observable para los servicios de Adsgency Digital. La puntuación es una ayuda para revisar, no una afirmación de que la empresa necesita un servicio.

## Servicios que se pueden recomendar

- Página web / landing page
- Rediseño o mejora web
- Gestión de redes sociales y contenido
- Publicidad digital (Meta Ads, Google Ads o TikTok Ads)
- SEO y presencia en buscadores

## Señales observables

### Sitio web

- No se encontró un sitio web oficial: posible oportunidad de página web; confirmar que la búsqueda no haya omitido un dominio.
- El sitio responde con error o parece abandonado: posible oportunidad de revisión; registrar fecha y evidencia.
- El sitio funciona en móvil y carga correctamente: no inferir una necesidad de rediseño sin otras señales.
- Tienda electrónica ausente en una empresa que vende productos en línea: posible oportunidad de comercio electrónico, solo si la actividad pública respalda esa hipótesis.

### Redes sociales

- No se encontraron perfiles oficiales: señal de baja confianza, porque los perfiles pueden estar bajo otro nombre.
- Perfil público con actividad reciente pero sin sitio web enlazado: posible oportunidad de landing page o web.
- Publicaciones comerciales regulares sin llamadas a la acción claras o sin un destino web verificable: posible oportunidad de optimización; registrar ejemplos concretos.

### Publicidad y SEO

- No detectar un píxel o etiqueta publicitaria no demuestra que la empresa no haga anuncios.
- La ausencia de un resultado orgánico destacado no demuestra por sí sola un problema de SEO.
- Estas señales requieren evidencia adicional y deben marcarse como indicios, no como hechos concluyentes.

## Puntuación inicial (0–100)

- 25 puntos: evidencia verificada de ausencia de sitio web oficial.
- 20 puntos: sitio web inaccesible en dos comprobaciones separadas o con error persistente.
- 15 puntos: perfil social oficial enlazado pero sin destino web útil.
- 15 puntos: actividad comercial visible y actualizada que hace plausible una mejora digital.
- 10 puntos: información de contacto empresarial publicada en una fuente oficial.
- 10 puntos: actividad y tamaño compatibles con el servicio ofrecido.
- 5 puntos: evidencia reciente y URL de fuente conservada.

Aplicar solo los puntos respaldados por evidencia. No sumar puntos por un dato desconocido. Limitar a 100.

## Niveles

- 75–100: prioridad alta para revisión humana.
- 50–74: prioridad media.
- 0–49: prioridad baja o evidencia insuficiente.

## Reglas de calidad

- Guardar URL de evidencia y fecha de consulta para cada señal.
- Deduplicar por RUC cuando esté disponible; como alternativa, normalizar dominio y nombre de empresa.
- No marcar correo como verificado salvo que exista una comprobación explícita y fiable.
- Separar datos oficiales de hipótesis generadas por reglas.
- No recopilar información personal sensible ni contactar automáticamente a nadie.
- Toda empresa debe revisarse manualmente antes de añadirla a una campaña.
